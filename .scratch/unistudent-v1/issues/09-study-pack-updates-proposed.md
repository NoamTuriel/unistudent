# 09: Study pack updates proposed, not overwritten

**What to build:** When new material affects a unit that already has a study pack, the plugin produces a change list (e.g. "2 new questions for topic 3, add them?") and applies only what the student approves. Raw and the Wiki are still rewritten freely.

**Blocked by:** 05, 08

**Status:** ready-for-agent

- [ ] Existing study pack files are never modified without explicit approval
- [ ] The change list names each proposed change and its source
- [ ] Approved changes are applied; rejected ones are not re-proposed for the same material
