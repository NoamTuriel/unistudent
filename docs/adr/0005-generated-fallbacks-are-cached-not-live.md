# Generated university/course fallbacks are interviewed once, then cached

When no plugin exists for a student's university or course, the plugin interviews the student once (site URL, how they organize material) and writes the result to a local reference file, in the same shape a hand-authored plugin would use (e.g. `plugins/openu/skills/openu-sync/references/site.md`). It is never re-researched live in a later session. We chose this over live per-session lookup because most AI tools this plugin supports have no reliable browsing capability, and unverified live scraping-instruction generation risks silently missing or misreading a site with no one noticing; a cached, student-confirmed file behaves identically to a hand-authored plugin from then on, including in tools with no browsing capability at all.
