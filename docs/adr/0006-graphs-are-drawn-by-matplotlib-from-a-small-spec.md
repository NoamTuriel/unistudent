# Graphs are drawn by matplotlib from a small spec, and saved as PNG

When a course explains something with a graph, the study pack reproduces it. The AI writes a short text description of the graph (axes, lines, curves, points, shifts); `us graph` turns it into a picture with matplotlib and saves a PNG next to the description. We chose this over having the AI write the picture itself (thousands of tokens per graph, and misplaced curves) and over a third-party Desmos or GeoGebra MCP (a headless browser or an app to install, no use of the course's own labels). PNG is the saved format because Google Docs does not render SVG and Word, OneNote and Obsidian all accept PNG.

matplotlib is added to the server's default launch so most students need to install nothing. This is a deliberate exception to "standard library only" for the default launch; the code still imports it behind `try/except ImportError`, so any other install works and says how to add it. Without it, `us graph` draws nothing and the study pack links the slide page and describes the graph in words instead.
