# Picture tools per field, fetched on demand and offered before the first Study pack

A Study pack should look like the course teaches. Graphs (ADR 0006) fit economics; other fields teach with other pictures (circuits, structures, constructions). So `us draw <kind> <spec>` is one dispatcher with one small drawer per kind, each declaring the one library it needs, and the plugin offers the tools that fit a course once, before its first Study pack. This builds on ADR 0006, which stays the decision for X-Y Graphs.

The library is not part of the server's launch. When the kind's package is not importable, the same command runs again in `uv run --with <package>`, which downloads and caches it: no restart and no config edit, the same on Windows, macOS and Linux, and `uv` is already required. This supersedes ADR 0006's exception that put matplotlib in the default launch; matplotlib is now the first kind and fetches itself on first use, without asking, because every graph needs it. If the fetch fails, the Study pack links the slide page and describes the picture in words, so nothing blocks.

A tool qualifies only if it is free, needs no account or key, runs offline on all three systems, installs in one step, and is driven by a short text spec. The offer is at most three tools, chosen by what the course Wiki actually shows (the field only when the Wiki says little), worded by what each will draw in this course, and answered once ("all", "none" or a pick). The answer is kept in the course settings and shown in the context file, so later units do not ask again. A field with no curated list gets a once-generated fallback that the student confirms (ADR 0005), never trusted unconfirmed. Each Study pack ends its How-to-start with "The plugin now supports: X, Y, Z", so a student who sees a picture learns they can ask for it in chat.

We chose this over adding every library to the default launch (every student downloads what only some need) and over a third-party Desmos or GeoGebra MCP (ADR 0006's reasons still hold). Mermaid flows are unchanged and are listed as supported.
