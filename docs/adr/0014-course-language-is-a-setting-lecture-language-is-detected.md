# The course language is a setting; the lecture language is detected per recording

A course folder speaks one language, the course language: its folder names, the Wiki's notes, the answers, the study packs and the recording summaries. Setup asks for it first, before the university, and recommends "same as my course": it works out the language the course is taught in from the course name, the university and the student's files, and confirms it in one line. A student who wants another language gets their notes and answers in it. Until the course is known, setup talks in the language the student writes in. The code assumes no language: `us setup` needs one for a new course, and courses set up before keep the one they stored.

The language spoken in a recording is not a setting and is never asked. One course can have a guest lecture in English and the rest in Hebrew, and a student cannot be expected to know this before the recordings arrive. Each recording's language is detected when it is transcribed, by Whisper's small multilingual `tiny` model on five 30-second clips spread over the recording: the language most heard among the clips that hold speech wins (a clip of silence, a break or a lecture's first minutes names a random language, with every model size; on 123 real Hebrew lectures the vote named Hebrew every time and a synthetic English clip English, in 1 to 10 seconds each); then the transcription model is picked for that language (the Hebrew-tuned ivrit.ai models for Hebrew, the multilingual model otherwise). Detecting with the transcription model itself does not work: a language-tuned model hears every language as its own, and the Hebrew one wrote an English clip out in Hebrew. The detected language is written in the transcript's frontmatter. Transcripts stay in the spoken language; summaries are written in the course language.

Hebrew and English have built-in label tables. For any other language, setup has the AI translate the table once (`us labels`), shows the student the folder names, and saves them with `us setup --labels`; the code uses them over the built-in table. This replaces the old fallback to English folder names, so a student anywhere gets folders in their own language without a code change.

This changes the setup order of ADR 0013 (language is now step 1) but not its shape: every question still comes first.
